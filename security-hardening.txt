================================================================================
  SECURITY HARDENING GUIDE - Dashboard Management Affiliate
================================================================================


1. WAF (Web Application Firewall)
---------------------------------
  Filter malicious traffic sebelum masuk aplikasi.
  - Cloudflare (free): auto WAF rules, DDoS protection
  - Nginx: mod_security, rate limiting
  - Bun: trustedProxy, request size limit


2. DDoS Protection
------------------
  Cegah traffic flood.
  - Cloudflare DDoS protection (free, auto)
  - Rate limiting per IP
  - Request size limit: max 10MB
  - Connection timeout: 30s
  - Max concurrent connections per IP


3. SSL/TLS & HTTPS
------------------
  Enkripsi traffic client <-> server.
  - Cloudflare SSL (free, auto-renew)
  - Let's Encrypt + Certbot (self-managed)
  - Redirect HTTP -> HTTPS
  - Minimum TLS 1.2, prefer TLS 1.3
  - HSTS: max-age=31536000; includeSubDomains; preload


4. Security Headers
-------------------
  Perintah ke browser untuk membatasi perilaku.
  - Content-Security-Policy: default-src 'self'
  - X-Content-Type-Options: nosniff
  - X-Frame-Options: DENY
  - X-XSS-Protection: 1; mode=block
  - Referrer-Policy: strict-origin-when-cross-origin
  - Permissions-Policy: camera=(), microphone=(), geolocation=()
  - Strict-Transport-Security: max-age=31536000


5. CSP (Content Security Policy)
--------------------------------
  Batasi sumber daya yang bisa dimuat halaman.
  - default-src 'self' (hanya dari origin sendiri)
  - script-src 'self' (block inline script)
  - style-src 'self' 'unsafe-inline' (Tailwind)
  - img-src 'self' data: https: (gambar external)
  - connect-src 'self' ws: wss: (WebSocket)
  - frame-ancestors 'none' (cegah iframe embed)
  - Report-Only mode dulu, lalu enforce


6. CSRF Protection
------------------
  Cegah cross-site request forgery.
  - Hono: CSRF middleware
  - Token di setiap form POST/PUT/DELETE
  - SameSite=Strict pada cookies
  - Origin/Referer header check
  - Custom header untuk AJAX (X-Requested-With)


7. XSS Protection
-----------------
  Cegah cross-site scripting.
  - TSX auto-escape output (Hono JSX aman)
  - Jangan raw() kecuali trusted
  - CSP header (no inline script)
  - Strip HTML tags dari user input
  - Sanitasi URL parameter


8. SQL Injection Protection
---------------------------
  Cegah SQL injection.
  - bun:sqlite + parameterized queries (aman default)
  - JANGAN string concatenation
  - Semua query pakai ? placeholder
  - Validate input type sebelum query
  - Gunakan query builder jika bisa


9. Input Validation & Sanitization
----------------------------------
  Validasi semua input user.
  - Hono + Zod / Valibot
  - Sanitasi: strip HTML, trim, max length
  - Type coercion: pastikan number = number
  - White-list approach (tolak kecuali allowed)
  - Regex untuk email, URL, slug


10. Authentication & MFA
-------------------------
  Verifikasi identitas user.
  - Better Auth: email OTP (MFA via email)
  - Password: min 8 char, 1 upper, 1 number, 1 special
  - Rate limit: max 5 attempt / 15 menit per IP
  - Lockout: 5x gagal -> kunci 15 menit
  - Audit log: catat semua login attempt


11. Secure Session Management
-----------------------------
  Kelola session dengan aman.
  - Better Auth: auto-handle session cookies
  - Cookie: httpOnly, Secure, SameSite=Strict
  - Session expiry: 24 jam
  - Session ID: random, min 128-bit entropy
  - Rotate session ID after login
  - Invalidate on logout / password change
  - No session in URL / localStorage


12. Access Control & RBAC
-------------------------
  Batasi akses berdasarkan role.
  - adminMiddleware: hanya admin ke /admin/*
  - authMiddleware: semua user harus login
  - Resource ownership: user hanya lihat data sendiri
  - Better Auth: role field di user table
  - Principle of least privilege


13. Rate Limiting
-----------------
  Batasi request per waktu.
  - Cloudflare: rate limiting rules (free)
  - Hono: rate limiter middleware
  - Login: 5 req / 15 menit per IP
  - API: 60 req / menit per user
  - SSE: 1 concurrent stream per user
  - General: 100 req / menit per IP


14. Bot Protection
------------------
  Cegah bot / scraper.
  - Cloudflare Bot Management (free)
  - Honeypot fields di form
  - reCAPTCHA / hCaptcha di login
  - User-agent check
  - Request timing analysis


15. API Security
----------------
  Amankan API endpoints.
  - Semua API route wajib auth
  - API key rotation
  - Request body size limit
  - Timeout: 30s semua API call
  - CORS: whitelist origin
  - Jangan expose stack trace di error
  - Log semua API call


16. Secure Cookies
------------------
  Amankan cookie session.
  - httpOnly: true (no JS access)
  - secure: true (HTTPS only)
  - sameSite: "Strict" (anti CSRF)
  - path: "/"
  - maxAge: 86400 (24 jam)
  - domain: explicit, no wildcard
  - Prefix: __Host-


17. Database Security
---------------------
  Amankan data di SQLite.
  - WAL mode [DONE]
  - Foreign keys ON [DONE]
  - File permission: 600
  - Backup: daily cron job
  - No raw SQL in logs
  - Encrypt sensitive columns (bcrypt) [DONE]
  - Vacuum secara berkala


18. Encryption
--------------
  Enkripsi data sensitif.
  - Password: bcrypt [DONE]
  - API keys/tokens: AES-256-GCM at rest
  - Session: encrypted di DB
  - JWT: HS256 (Better Auth)
  - .env tidak di-commit [DONE]
  - TLS 1.3 untuk data in transit


19. Secrets Management
----------------------
  Kelola secrets dengan aman.
  - .env: local dev only
  - Production: env vars via Docker/systemd
  - JANGAN hardcode secrets
  - JANGAN commit .env [DONE - .gitignore]
  - Rotate secrets secara berkala
  - Vault/secret manager untuk production


20. Secure Backups
------------------
  Backup data dengan aman.
  - Daily backup SQLite
  - Backup dienkripsi
  - Simpan di lokasi berbeda
  - Retensi: 7 hari
  - Test restore berkala
  - Backup automation


21. Logging & Monitoring
------------------------
  Lacak aktivitas dan deteksi anomali.
  - Login attempts: success/failure + IP + timestamp
  - API calls: method, path, status, duration, user
  - Error logs (jangan expose ke client)
  - Rate limit events
  - Security events: failed auth, invalid token, CSRF block
  - Log format: structured JSON
  - Log retention: 30 hari
  - Monitoring: health check, uptime alert
