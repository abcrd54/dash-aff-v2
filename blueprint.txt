================================================================================
  BLUEPRINT - Dashboard Management Affiliate
================================================================================


TUJUAN UTAMA
------------
Sistem all-in-one untuk management post, konten, dan share link affiliate
di social media. Dari membuat akun, menghubungkan platform, generate konten
dengan link affiliate, sampai auto posting.


GAMBARAN BESAR
--------------
4 langkah utama:
  1. Buat Akun Bunsocial
  2. Hubungkan Platform
  3. Generate Konten + Link Affiliate
  4. Auto Post

Dua jalur konten:
  A. Akun Persona (sentuhan manusia)
     AI caption by persona -> Generate gambar -> Auto post
  B. Akun Scraping (full otomatis)
     Scrape berita -> Generate caption -> Generate gambar -> Auto post


APA ITU BUNDLE SOCIAL?
----------------------
Platform agregator social media. TIDAK PERLU pakai API masing-masing
platform (Facebook, X, Instagram, dll). Cukup hubungkan ke Bundle Social,
lalu semua posting dilakukan lewat Bundle Social.

  Facebook, X, Instagram, dll  -->  Bundle Social  -->  Dashboard

Batasan: 1 akun Bunsocial = maksimal 20 post/bulan.


KENAPA BUTUH BANYAK AKUN?
-------------------------
Karena batasan 20 post/bulan, satu nama akun butuh banyak Bunsocial.

  Info Dunia:
    Bunsocial #1 -> 20 post
    Bunsocial #2 -> 20 post
    Bunsocial #3 -> 20 post
    Bunsocial #4 -> 20 post
    Total: 80 post/bulan

Satu postingan dikirim ke semua Bunsocial dalam grup yang sama via
Bundle Social, sehingga reach-out lebih besar.


DUA JENIS AKUN
--------------

A. Akun Persona (Sentuhan Manusia)
   Akun dengan identitas seperti orang asli.
   Contoh: Maya Putri - hobi naik gunung, fotografi, traveling.

   Alur: AI Caption -> Review & edit -> Generate gambar -> Approve -> Post
   Status: Caption DONE | Gambar COMING | Post COMING

B. Akun Scraping (Full Otomatis)
   Konten dari scraping berita, semua data sudah disediakan.
   Contoh: Info Dunia - sumber Detik.com.

   Alur: Scrape -> AI Caption -> AI Gambar -> Post (full otomatis)
   Status: COMING SOON


AI GENERATION - jadiapa.com
---------------------------
Platform penyedia model AI untuk generate konten. Dashboard terhubung
langsung ke jadiapa.com.

Layanan:
  - Generate Gambar: AI bikin gambar dari prompt   [COMING]
  - Generate Video:  AI bikin video pendek         [COMING]

Dashboard panel: saldo, pemakaian, top up, generate - semua dari dalam

Scraping data:
  - Saldo              -> tampilkan sisa saldo
  - Riwayat pemakaian  -> lacak konsumsi
  - Harga per generate -> hitung biaya
  - Status top up      -> konfirmasi

Flow: Input prompt -> Cek saldo -> Submit -> Tunggu hasil -> Tampilkan


LINK AFFILIATE - Jantung Sistem
-------------------------------
Setiap konten harus mengandung link affiliate (Shopee, Tokopedia).
Sumber monetisasi dari klik & pembelian.

Dua cara input:
  1. Manual     -> input link -> scrape produk -> AI caption
  2. Otomatis   -> scrape dashboard -> pilih produk -> generate

Dua jenis scraping Shopee:
  - Scraping Produk    : nama, harga, deskripsi, gambar
    (dipakai semua jalur)
  - Scraping Dashboard : views, klik, komisi, trending
    (hanya jalur otomatis)

Penempatan link:

  Opsi A: Link di Caption
    "Sepatu ini nyaman! Cek: https://s.shopee.co.id/xxx"
    Cocok: X, Threads, TikTok, Pinterest

  Opsi B: Link di Komentar (caption natural)
    Caption:  "Sepatu hiking ini nyaman banget! Cocok buat pemula..."
    Komentar: "Yang mau sepatu hiking https://s.shopee.co.id/xxx"
    Cocok: FB, Instagram (aman, gak kena penalti algoritma)

  Default: komentar (lebih aman), bisa dikonfigurasi per platform.


ALUR UTAMA
----------

1. BUAT AKUN BUNSOCIAL
   Input:  Jumlah + Nama akun (Info Dunia, dll)
   Proses: Email disposable -> Register -> Verifikasi -> Setup
           -> API Key -> Buat Team
   Output: Akun siap pakai (API key + team ID)

2. HUBUNGKAN PLATFORM
   Input:  Akun Bunsocial
   Proses: Pilih platform -> OAuth Bundle Social -> Login
           -> Pilih Page/Channel -> Verifikasi
   Output: Akun terhubung ke platform (FB,IG,X,TK,Threads,Pin)

3. GENERATE KONTEN - Jalur A (Persona)
   Input:  Persona + Topik + Link Affiliate
   Proses: Pilih link -> AI caption by persona -> Review
           -> Generate gambar -> Approve
   Output: Konten siap posting

4. GENERATE KONTEN - Jalur B (Scraping)
   Input:  Niche + Sumber berita + Link Affiliate
   Proses: Scrape berita -> Scrape dashboard -> AI caption
           -> AI gambar -> Full otomatis
   Output: Konten siap posting

5. AUTO POST
   Input:  Nama akun + Konten
   Proses: Pilih grup -> Semua Bunsocial terpilih -> Post via Bundle
   Output: Konten terposting ke semua platform

6. SCHEDULE POSTING [COMING]
   Jadwal otomatis sesuai prime time, delay 1-5 menit antar akun

   Prime Time (Sprout Social 2026, 2 miliar engagement):
   - Facebook  : 12-20 WIB, Selasa-Rabu
   - Instagram : 12-21 WIB, Selasa-Rabu
   - X/Twitter : 12-18 WIB, Selasa-Kamis
   - TikTok    : 13-20 WIB, Rabu-Kamis
   - Threads   : 12-18 WIB, Selasa-Kamis
   - Pinterest : 10-13 WIB, Selasa-Kamis
   - Minggu = hari terburuk di semua platform

7. AUTO RETRY [COMING]
   Analisis views & klik -> Produk bagus auto repost -> Produk sepi stop
