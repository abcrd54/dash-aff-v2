TUJUAN UTAMA
--------------------------------------------------------------------------------
Sistem all-in-one untuk management post, konten, dan share link affiliate di
social media. Dari membuat akun, menghubungkan platform, generate konten dengan
link affiliate, sampai auto posting — semua dalam satu dashboard.


GAMBARAN BESAR
--------------------------------------------------------------------------------
[1] Buat Akun Bunsocial
[2] Hubungkan Platform
[3] Generate Konten + Link Affiliate
[4] Auto Post

DUA JALUR KONTEN:
  Jalur A: Akun Persona (sentuhan manusia)
           AI caption by persona identity -> Generate gambar -> Auto post

  Jalur B: Akun Scraping (full otomatis)
           Scrape berita Detik -> Generate caption -> Generate gambar -> Auto post


APA ITU BUNDLE SOCIAL?
--------------------------------------------------------------------------------
Bundle Social adalah platform agregator social media. Kita TIDAK PERLU pakai API
masing-masing platform (Facebook API, X API, Instagram API, dll). Cukup hubungkan
akun ke Bundle Social, lalu semua posting dilakukan lewat Bundle Social.

  Facebook ---\
  X ------------> Bundle Social ---> Dashboard Management
  Instagram ---/

Batasan: 1 akun Bunsocial = maksimal 20 post/bulan di Bundle Social.


KENAPA BUTUH BANYAK AKUN BUNSOCIAL?
--------------------------------------------------------------------------------
Karena batasan 20 post/bulan, satu "nama akun platform" butuh banyak akun.

  Nama Akun: Info Dunia
    Bunsocial #1 -> 20 post/bulan
    Bunsocial #2 -> 20 post/bulan
    Bunsocial #3 -> 20 post/bulan
    Bunsocial #4 -> 20 post/bulan
    Total: 80 post/bulan untuk "Info Dunia"


DUA JENIS AKUN SOSIAL MEDIA
--------------------------------------------------------------------------------

A. Akun Persona (Sentuhan Manusia)
   Akun dengan identitas seperti orang asli — hobi, kesukaan, kepribadian.
   Contoh: Maya Putri — hobi naik gunung, fotografi, traveling

   Alur: AI Generate Caption (by persona) -> Review & edit -> Generate gambar
         -> Review & approve -> Auto post

   Status: Caption DONE | Generate gambar COMING | Auto post COMING

B. Akun Scraping (Full Otomatis)
   Akun yang kontennya dari scraping berita — semua data disediakan.
   Contoh: Info Dunia — sumber Detik.com

   Alur: Scrape berita -> AI caption -> AI gambar -> Auto post (full otomatis)

   Status: COMING SOON (flow & arsitektur)


AI GENERATION — jadiapa.com
--------------------------------------------------------------------------------
jadiapa.com adalah platform penyedia model AI untuk generate konten. Dashboard
terhubung langsung ke jadiapa.com untuk semua kebutuhan AI.

Layanan:
  - Generate Gambar: AI bikin gambar dari prompt    [COMING]
  - Generate Video:  AI bikin video pendek          [COMING]

Integrasi Dashboard:
  Saldo, pemakaian, top up, generate — semua dari dalam dashboard.

Scraping jadiapa.com:
  - Saldo              -> Tampilkan sisa saldo
  - Riwayat pemakaian  -> Lacak pemakaian
  - Harga per generate -> Hitung biaya
  - Status top up      -> Konfirmasi pembayaran

Flow Generate:
  User input prompt -> Cek saldo -> Submit generate -> Tunggu hasil -> Tampilkan


LINK AFFILIATE — Jantung Sistem
--------------------------------------------------------------------------------
Setiap konten yang diposting harus mengandung link affiliate (Shopee, Tokopedia).
Link affiliate adalah sumber monetisasi.

Dua Cara Input:
  1. Manual:  User input link -> Scrape data produk -> AI generate caption
  2. Otomatis: Scrape dashboard affiliate -> Pilih produk terbaik -> Generate

Dua Jenis Scraping Shopee:
  - Scraping Produk:             Nama, harga, deskripsi, gambar
  - Scraping Dashboard Affiliate: Views, klik, komisi, produk trending

Penempatan Link Affiliate:
  Opsi A: Link di Caption
    "Sepatu hiking ini nyaman! Cek: https://s.shopee.co.id/xxx"
    Cocok: X, Threads, TikTok, Pinterest

  Opsi B: Link di Komentar (caption natural, tanpa sebut "cek komentar")
    Caption:  "Sepatu hiking ini nyaman banget! Cocok buat pemula..."
    Komentar: "Yang mau sepatu hiking berkualitas https://s.shopee.co.id/xxx"
    Cocok: FB, Instagram (tidak kena penalti algoritma)

  Platform           Link di Caption    Link di Komentar
  Facebook           Reach turun        AMAN
  Instagram          Reach turun        AMAN
  X (Twitter)        Normal             Bisa
  TikTok             Normal             Bisa
  Threads            Normal             Bisa
  Pinterest          Normal             Bisa

  Default: Link di komentar (lebih aman). Bisa dikonfigurasi per platform.


ALUR UTAMA
--------------------------------------------------------------------------------

1. BUAT AKUN BUNSOCIAL
   Input:  Jumlah akun + Nama akun (Info Dunia, Info Bisnis, dll)
   Proses: Generate email -> Register -> Verifikasi -> Setup profil
           -> Generate API key -> Buat team
   Output: Akun Bunsocial siap pakai (API key + team ID)

2. HUBUNGKAN PLATFORM
   Input:  Akun Bunsocial
   Proses: Pilih platform (FB,IG,X,TK,Threads,Pin) -> OAuth Bundle Social
           -> Login & izinkan -> Pilih Page/Channel -> Verifikasi
   Output: Akun terhubung ke platform via Bundle Social

3. GENERATE KONTEN — Jalur A (Persona)
   Input:  Persona + Topik + Link Affiliate
   Proses: Pilih link (manual/auto) -> AI caption by persona identity
           -> Review & edit -> Generate gambar -> Review & approve
   Output: Konten siap posting (caption + link + gambar)

4. GENERATE KONTEN — Jalur B (Scraping)
   Input:  Niche + Sumber berita + Link Affiliate
   Proses: Scrape berita -> Scrape dashboard affiliate -> AI caption
           -> AI gambar -> Full otomatis
   Output: Konten siap posting (caption + link + gambar)

5. AUTO POST
   Input:  Nama akun + Konten
   Proses: Pilih grup -> Semua Bunsocial dalam grup terpilih
           -> Post via Bundle Social -> Distribusi ke semua platform
   Output: Konten terposting ke semua platform dalam grup

6. SCHEDULE POSTING [COMING]
   Input:  Konten + Jadwal
   Proses: Sistem tentukan jadwal optimal -> Posting otomatis
           -> Delay 1-5 menit antar akun -> Bisa override manual

   Prime Time (Sprout Social 2026 - 2 miliar engagement):
   Platform       Waktu Terbaik       Hari Terbaik      Hari Terburuk
   Facebook       12:00 - 20:00       Selasa, Rabu      Akhir pekan
   Instagram      12:00 - 21:00       Selasa, Rabu      Akhir pekan
   X (Twitter)    12:00 - 18:00       Selasa - Kamis    Akhir pekan
   TikTok         13:00 - 20:00       Rabu, Kamis       Akhir pekan
   Threads        12:00 - 18:00       Selasa - Kamis    Akhir pekan
   Pinterest      10:00 - 13:00       Selasa - Kamis    Akhir pekan
   Catatan: Hari Minggu adalah hari terburuk di semua platform.

7. AUTO RETRY PRODUK BAGUS [COMING]
   Input:  Data performa dari dashboard affiliate
   Proses: Analisis views & klik -> Produk views tinggi -> auto repost
           -> Produk sepi -> berhenti
   Output: Produk best-performing terus dipromosikan
